# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: **Security** tab, **Report a vulnerability**
(private vulnerability reporting). Do not open a public issue for them.

Include what you found, how to reproduce it, and the impact. You can expect an acknowledgement within a few days.

## Scope

This repository is a test suite. In scope: leaked secrets or session data in the repository or its CI artifacts, and unsafe
workflow configuration. Out of scope: vulnerabilities in the website the suite tests; report those to its vendor through
their own channel.

## If you find a credential

Do not use it. Report it as above so it can be rotated.
