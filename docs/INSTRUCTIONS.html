Reviewer walkthrough

Playwright + TypeScript automation for the signup and login flows of a configured website. This page is only a short entry point; the details live in the documents below.

Quick start

Needs Node.js 22+ and network access to the site under test. Set TARGET_APP_URL and TARGET_SSO_URL in .env (see .env.example). Full setup: docs/ONBOARDING.md.

npm ci
npx playwright install --with-deps chromium
npm run typecheck
npm test            # chromium
npm run report      # open the HTML report
It runs against the live production site. Do not loop it: repeated logins trigger the site's captcha and those tests then skip. A skip means not verified, never passed.

Cautions

  • Secrets. .env and .auth/user.json (live tokens) are git-ignored; never commit or share them.
  • Live signup (AF-SIGNUP-06) creates a real account and is off by default.
  • Known issue. AF-SIGNUP-04 (terms not accepted) is intermittent on the site; see the README.
If anything here drifts, the README and the documents above are the source of truth.
